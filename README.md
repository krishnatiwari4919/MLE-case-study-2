# Credit Card Fraud Detection

This project detects fraudulent transactions using **XGBoost** on a highly imbalanced dataset. **SMOTE** is applied only to training data to handle class imbalance. Different decision thresholds are tested to balance fraud detection and false alarms. Performance is evaluated using **precision, recall, F1-score, ROC-AUC, and confusion matrix**. XGBoost feature importance is used to interpret important transaction characteristics.
